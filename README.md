# BYC USB 烧录软件（BootLoader_Tools v3.5.7.1）

| 文件 | 说明 |
| --- | --- |
| `BootLoader_Tools_v3.5.7.1.exe` | 原版 |
| `BootLoader_Tools_v3.5.7.1_AutoDL.exe` | 增加了“自动下载模式”的版本 |
| `tools/add_auto_download.py` | 由原版生成 AutoDL 版和一键升级模板的补丁脚本（原程序没有源码，功能以二进制补丁方式加入） |
| `upgrader/Upgrader_Template.exe` | 一键升级程序的模板（本身不含固件，不直接使用） |
| `upgrader/make_upgrader.bat` | 把固件 `.bin` 拖到它上面，生成双击即可升级的 exe |
| `upgrader/make_upgrader.py` | 生成器（装了 Python 时使用，支持换图标等选项） |
| `upgrader/make_upgrader.ps1` / `make_upgrader.cs` | 生成器（没装 Python 时 bat 自动改用 Windows 自带的 PowerShell） |
| `upgrader/upgrader_icon.ico` | 升级程序的默认图标（由 `tools/make_default_icon.py` 生成） |

## 自动下载模式

窗口底部多了一个复选框 **“自动下载模式（设备接入后自动开始下载）”**。

用法：

1. 点“打开文件”选好烧录文件；
2. 勾选“自动下载模式”；
3. 插入设备。之后每插入一只设备都会自动走完 切换 BOOT → 下载 → 校验 → 跳转 APP，
   不用再点“下载程序”。看到“程序更新成功！”后拔掉，换下一只即可。

行为说明：

- 设备以正常模式或 BOOT 模式接入都会触发。
- 没选烧录文件、或没勾选时，行为与原版完全一样。
- 刚烧完的设备跳回 APP 重新枚举时不会被再烧一遍（成功后 15 秒内的那一次接入会被忽略）。
- 下载失败不会自动重试，重新插拔设备才会再次触发。
- 勾选时已经连着的设备不会立刻开始下载，对它点一次“下载程序”或重新插拔。
- 勾选状态会记住：点击复选框时立即保存到注册表
  `HKEY_CURRENT_USER\Software\BYC\BootLoader_Tools` 的 `AutoDownload`，下次启动自动恢复（按 Windows 用户保存）。
- 烧录文件不会记住，每次启动后要重新“打开文件”；选好文件之前即使已勾选也不会触发下载。
- 点了“读取程序”时仍然执行读取，不会被自动下载抢走。

## 一键升级程序（把 .bin 做成双击即可升级的 exe）

生成：

- 把固件 `.bin` 拖到 `upgrader/make_upgrader.bat` 上（可以一次拖多个），会在 `upgrader` 文件夹里生成
  `<名称>_升级.exe`。不需要安装任何东西：装了 Python 3 就用 Python，没装就自动改用 Windows 自带的
  PowerShell。窗口会停住显示结果，按回车关闭。或者
- 命令行（需要 Python 3，只用标准库）：

```bash
python upgrader/make_upgrader.py 固件.bin
```

可选参数：`-o 输出.exe` 指定输出文件，`--title "窗口标题"` 指定窗口标题（默认“固件升级”），
`--auto-exit` 升级成功 1 秒后自动退出（默认不退出，由用户点右上角关闭），
`--icon 图标.ico` 换成自己的图标（换图标需要 Python；走 PowerShell 时用默认图标）。

生成后会自动打开 `upgrader` 文件夹并选中生成的 `<名称>_升级.exe`。
注意：`upgrader/Upgrader_Template.exe` 只是模板，里面没有固件，直接双击它会弹出说明后退出。

使用：把生成的 `<名称>_升级.exe` 发给使用者，双击打开，插入设备即自动升级。
升级成功后进度条右边显示“升级成功”，由用户点右上角的关闭按钮退出。
不需要另外的 `.bin`，也不用点“打开文件”“下载程序”。升级失败时程序不会退出，
进度条变红，右边出现“重试”按钮。

- 固件就附加在 exe 文件末尾，运行时程序以只读方式打开自身读取，不会解压出任何文件。
- 版本、校验和的显示，与芯片是否匹配的检查，以及下载、校验、跳转 APP 的流程，都和原版选文件烧录时一样。
- 打开程序时已经插着的设备会直接开始升级。
- 键盘以正常模式插入后，等 1 秒再发“切换到 BOOT”命令（刚插上的设备可能还没准备好）。
  如果 15 秒内没有切换成功，会自动重发，最多 3 次；仍不行就显示失败和“重试”按钮，不会一直停在 0%。
- 打开一次只能升级一次：升级成功后程序保持打开，一直显示满格和“升级成功”，由用户点右上角的关闭按钮退出；
  之后再插拔设备都不会再升级。要升级下一台，关掉程序重新打开。升级失败不算次数，可以点“重试”或重新插拔。
- 点“读取程序”成功后不会自动退出。
- 进度是连续的：下载占 0~85%，下载后的校验占 85~100%（原程序校验时会把进度条清零重来）。
  比例按两段实际的 USB 传输次数分配（下载约 6 次/128 字节，校验 1 次），所以前后两段走得一样快。
  每次更新都立即画到位，不再等系统动画（原程序下载时界面不刷新，进度条会一顿一顿地跳）。
  校验进度按固件的实际长度计算（原程序按芯片 Flash 大小算，固件较小时校验进度会在最后跳一大段）。
- 界面只有一个进度条，右边的文字平时显示百分比，没插设备时显示“请插入你的键盘”，
  升级成功后显示“升级成功”；标题栏只显示“固件升级”，右上角有关闭按钮。其它按钮和文字信息都隐藏了。
- 外观：白色背景，微软雅黑字体；右侧文字加大加粗，百分比为深灰色、“请插入你的键盘”为蓝色、“升级成功”为绿色。
- 升级失败时进度条变红、右边出现“重试”按钮，点它重新升级（设备已拔出时会提示插入）；
  拔出重插设备也会自动重试。
- 图标：默认是蓝底白色芯片加绿色向上箭头。想用自己的图标，把 `.ico` 和 `.bin` 一起拖到
  `make_upgrader.bat` 上，或者加 `--icon 图标.ico`；也可以用不超过 256×256 的正方形 `.png`。
  `.ico` 里最好包含 16、32、48、256 几种尺寸，小图标才清楚。
- 一个 `.bin` 对应一个升级程序；换固件请用原始的 `Upgrader_Template.exe` 重新生成，
  已经装过固件的 exe 不能再当模板用。
- 不要对生成的 exe 做数字签名，签名会附加在文件末尾，导致读不到固件。

## 重新生成

```bash
pip install pefile capstone
```

```bash
python3 tools/add_auto_download.py
```

```bash
python3 tools/add_auto_download.py --upgrader
```

第一条生成 AutoDL 版，第二条生成 `upgrader/Upgrader_Template.exe`。另需安装 `nasm`。脚本会校验原版 exe 的 SHA-256，补丁的具体内容见脚本开头的说明。
